# Security Rules

- Threat-model authentication, authorization, user data, uploads, webhooks, payments, and external input.
- Validate input, encode output, protect sessions, and handle secrets outside source control.
- Apply least privilege and verify ownership server-side.
- Use rate limits and audit logging where abuse or accountability matters.
- Keep dependency vulnerabilities visible and addressed according to risk.
- Never weaken security controls to make a test or request pass.

Reason: security failures affect users and data beyond the immediate feature.
