# Release Gate

## Preconditions
Feature gate and all risk-required specialist gates are complete.

## Checklist
- [ ] Acceptance criteria are verified.
- [ ] Diagnostics and required tests pass.
- [ ] Security and performance findings are resolved or accepted.
- [ ] Migration, rollback, configuration, and observability needs are documented.
- [ ] Review findings are resolved.
- [ ] Documentation and knowledge are synchronized.

## Evidence
Command results, review report, gate checklist, docs/ADR links, and residual risk.

## Failure Conditions
Unverified claims, unresolved critical findings, unsafe migration, missing rollback consideration, or incomplete acceptance.

## Reviewer
Quality/Security and Reliability for high/critical changes; Product Mentor confirms acceptance.

## Exit Criteria
The feature is accepted with evidence and a clear follow-up list.
