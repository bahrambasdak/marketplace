# Testing Rules

- Test behavior and invariants at the lowest meaningful layer.
- Use real persistence behavior for persistence tests; mock external providers at adapters.
- Keep tests isolated, deterministic, and named by behavior and outcome.
- Add regression coverage for every fixed defect.
- Do not chase arbitrary coverage percentages.
- Match test depth to risk, with critical journeys covered end to end.

Reason: confidence comes from relevant evidence, not test volume.
